Tic-Tac-Toe Evolved

A classic game reimagined — built from scratch using up-to-date AI tools.
Unlike traditional Tic-Tac-Toe, this version requires you to align five matching pieces in a row to win, adding a fresh layer of strategy to a familiar game.

Features

 Two Game Modes — Play locally with a friend (2-Player mode) or challenge the AI.

 Player Profiles — Enter your name and track your progress.

 Ranking System — See how many games you've won and climb the leaderboard.

 Adaptive AI — The AI doesn't rely on fixed difficulty levels. Instead, it learns from every move you make. The more you play, the better      it gets at predicting your strategy — so the game naturally grows more challenging the more you play, keeping every match one step ahead.
